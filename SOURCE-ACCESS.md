# Getting the source code

This repository is the **public showcase** for **React Native (Expo) App Starter**: documentation, client case study, quality report and measured results. The source code is not published here.

## What you can do from here

- Read the [README](README.md) for the architecture, engineering decisions, quality bar and an honest list of what is and is not built.
- Read the [client case study](docs/case-study.md) for the business problem, value levers and engagement model.
- Read the [quality report](docs/quality-report.md) and inspect the raw measurements in [`results/`](results/) behind every figure.

## What the source package contains

- Complete source code (179 files), automated tests and a CI workflow
- The measurement scripts that regenerate everything in `results/`
- Setup and verification instructions, a changelog, a security policy and the license terms
- Version **0.1.0**, delivered as `expo-app-starter-0.1.0.zip`
